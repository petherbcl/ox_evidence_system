# ox_evidence_system
OX Lib based Evidence System

## Descrição
O `ox_evidence_system` é um sistema baseado na OX Library para gerenciamento de evidências em servidores FiveM. Ele permite que jogadores interajam com evidências no mundo do jogo, oferecendo funcionalidades como coleta, análise e armazenamento.

## Funcionalidades
- Coleta de evidências no ambiente do jogo.
- Armazenamento seguro de evidências.
- Integração com outros sistemas baseados na OX Library.
- Configuração personalizável para atender às necessidades do servidor.

## Requisitos
- **FiveM**: Servidor compatível com FiveM.
- **OX Library**: Certifique-se de que a biblioteca OX está instalada e configurada corretamente.

## Instalação
1. Baixe ou clone este repositório na pasta `resources` do seu servidor.
2. Adicione a seguinte linha ao seu arquivo `server.cfg`:
```ensure ox_evidence_system```
3. Reinicie o servidor.

## Configuração
Edite o arquivo de configuração principal para ajustar o sistema às necessidades do seu servidor. Consulte a documentação para mais detalhes.
